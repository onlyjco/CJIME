# CJIME V1.5 更新说明

## 26 键中文滑行整句引擎升级（P0 / P1 / P1.5 + 双拼专项优化）
- **音节晶格 + 词组 Trie + Trigram 联合束搜索**：中文 26 键滑行（全拼与双拼）新增词级三元语言模型联合束搜索，在轨迹剪枝前引入上下文语言概率；扁平化音节前缀树并将反向 DP 与经典兜底共享同一 `LatticeContext`，长句反向表构建提速约 14 倍，抬手编码上限放宽至 72 键。
- **首道及固定双键双拼滑行专项优化**：
  - 保留严格 `0.50` 主路径零额外开销，仅在圆角断路或高代价时启用 `0.50–0.65` 带罚次级弯边回退，并支持同键音节（如 `ee/ii/vv`）局部停留抵扣重复代价；
  - 长句统一 64 点 DTW 尺度与先验，在候选池末尾为完整帧覆盖的 ≥6 字长句预留 2 个竞争名额送入后级 Rime 重排；
  - 抬手甩尾检测改为仅识别偏离键心与抬手前高速急甩，按弧长精确插值截尾。
- **流式预览与备选候选修复**：统一预览与抬手校准缓存槽，新增 36ms 稳定前缀预览；修复 Rime 重排评分与展示候选错位，修复点选部分前缀后旧整句滑行备选仍残留在候选栏的问题；脱敏轨迹导出升级 `ver: 2`，记录真机三行行距与双拼偶数校验。

## 双拼整句与词组模型体验优化
- **双拼候选补齐长前缀与临界次选整句**：26 键双拼同步全拼的 `menu_prefixes: 3`（长句后提供按词切分的前缀候选方便一键修尾），并开启克制的 `menu_sentences: 2`（分差 ≤1.8 时才给出第 2 整句）。
- **清理「动词 + 的是」词库碎片**：清除 `ext/tencent` 中 `输入的是`、`打开的是`、`创建的是`、`输出的是` 等 11 条易吞掉后词 `shi` 音节的低频组合碎片，并补齐 `识别准确度`、`识别准确率` 等常见搭配。
- **词组模型热加载生效**：修复下载、切换或删除词组模型（`t9_ngram.lm`）后需手动强行停止输入法进程才生效的问题，原生路径与句柄缓存随安装/部署即时清理生效。

## 联想词精准度与个人学习修复
- **Trigram 显式三元残差与整词提升**：联想词复用内存映射 `t9_ngram.lm`，仅对显式命中的三元与 3–4 字整词二元叠加语境残差，避免回退常量相对压低未登录词。
- **个人学习负反馈与连续衰减**：修复新注入的个人词跳过负反馈扣分的问题，统一合并后再执行负反馈与衰减后准入门槛；将 45 天半衰期修正为连续平滑曲线并消除满 1 天跳变；新增整词后单字护栏与前排温和多样性整理。

## 布局、局部修改与交互修复
- **新增「乱序十七」内置 17 键双拼方案**：移植上游 `double_pinyin_lxsq17` 键位与方案配置，兼容精简底排。
- **局部修改输入对齐与下划线保护**：对齐局部修改模式与普通输入的滑行按音节删除逻辑；修复局部修改按空格后后续滑行编码下划线丢失，以及关屏重开或选区恢复后所有编码全带下划线的问题。
- **按键与设置界面修复**：修复合并 `123` 键长按进入符号面板返回后偶发吞下一次点击的问题；修复设置页底排逗号/句号预览卡片高度裁切问题。
