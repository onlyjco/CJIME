# CJIME V1.4 更新说明

## 符号与表情键盘重做
- **符号键盘右侧竖排同步数字键盘**：右上放置删除键（补齐普通/数字键盘同款「清空」角标、上滑清空/下滑撤回与滑动气泡提示），中间为空格键与锁定/单次返回切换键，右下为回车动作键（跟随当前输入框动作）。
- **表情键盘右侧竖排重做**：参考数字键盘右侧布局，顶部为删除键（带「清空」角标，颜文字模式下长按仍支持整条删除），最下为回车动作键，中间两格为 `Emoji` / `颜文字` 竖排切换选框（无底部横线干扰）。
- **表情「最近」下沉与标签记忆**：`Emoji` 与 `颜文字` 各自的底部二级分类首位均独立管理自己的「最近」记录，并支持记忆退出前的一级与二级标签，下次打开直接回到上次位置。

## 键盘交互与显示修复
- **修复数字/符号键盘左下角返回标签错乱**：修复从首道双拼等方案切入数字/符号键盘、或在数字/符号键盘中按底部语言切换键时，左下角返回文字与实际返回目标的中英文不一致的问题。
- **支持空格两侧标点自定义点按主符号**：在设置「按键符号」中点击空格两侧逗号/句号键时，可在「上方」与「下方」输入框之间直接自定义「点按（主符号）」，留空即恢复默认，中英文独立保存。
- **修复支持回车变发送的输入框按 Shift 时发送图标闪动**：持续按住 Shift 满 `180ms` 才将回车图标切换为换行提示，普通点按 Shift 不再闪一下回车图标，同时按住 Shift + 回车仍即时生效。
- **Shift 短锁定箭头统一配色**：激活态（短锁定与长锁定）填上主题强调色后统一优先使用白色箭头，仅在浅色/高亮强调色底上对比度不足时回退黑色。
- **无痕开关文字区分**：无痕卡片按状态明确显示为 `无痕(开)` / `无痕(关)`。
- **手写窗口返回与切换残影修复**：仅上一页直接为手写时返回手写，连续切换多个功能面板后返回一律回键盘；消除切入手写及工具栏图标切换时的残影与闪黑。
- **修复 Release 打包 `KeyboardResizeOverlayKt` 字节码校验异常**：将调节面板及局部组合函数提取为顶层私有函数，规避 R8 寄存器合并导致的 ART `VerifyError`。

## 合并主线（至 `1.15.108`）核心更新与滑行优化
- **引擎与词库**：并入双拼整句扩展、九键长句性能与候选稳定性优化、词库修正与口语短语补充、单字/缩写过滤器更新。
- **防杀后台与稳定性**：新增 OEM 后台防清理引导、进程退出原因记录、进程重启后恢复未完成编码、全屏手写底部避让修复。
- **输入体验增强**：支持纯中文 TXT 词库自动注音、英文词记忆隐私模式与忘词降权、笔画内联字形渲染、注音屏幕键盘回车上屏候选与逗号长按全角标点气泡、在线语音接口与方案管理修复。
- **滑行自学习护栏**：为 `delete_retype` 纠错新增键盘邻近/字符重合度护栏，避免删掉旧词改打完全无关内容时向混淆表与落点校准写入噪声。
