# CJIME V1.2 更新说明

## 新图标与视觉体验
- **全新 CJIME 品牌图标**：更换为深邃夜空底 + 蓝紫流光一笔「CJ」滑行轨迹矢量自适应图标，同步支持 Android 13+ 单色主题图标。
- **修复候选栏剪贴板切换与锁屏闪动**：
  - 消除清空剪贴板预览切回工具栏时的图标缩放跳动与淡入闪烁。
  - 带着粘贴内容关屏再开屏时保留预览状态，不再先闪一帧工具栏图标再切回粘贴内容。
  - 按回退键关闭剪贴板预览后同步标记已消费，锁屏亮屏不再重新冒出；收起再展开键盘与息屏重开行为统一。
- **修复局部修改后音节栏字号异常缩小**：统一参考宽度上限，避免长音节导致后续音节联想字号被整体压小。

## 候选展开与音节栏修复
- **展开候选与候选栏完全一致**：展开页与候选条扩展时同步合并首屏的连续滑行备选（`GlideAlternatives`）、通讯录与插件变换，展开后排序与点选行为与收起态保持一致；局部修改展开页不再重复列出顶部候选栏已显示的候选词。
- **修复单编码 / 简拼段音节栏不显示**：为双拼单字母及长输入末尾未打完的简拼段补齐 `ExpandSearch`（`kCompletion`）与简拼音节回退支持，不再回退显示为符号栏，且支持直接点选锁定读音。

## 滑行与智能联想自学习升级
- **滑行混淆表音节级泛化**：整句纠错时自动抽取局部差异音节对并建索引（兼容历史记录），后续在任意新句子滑到同款易混音节都能直接受益。
- **指腹落点偏移冷启动加速**：前 10~15 次样本采用自适应递减步长快速收敛，20 次后平滑落回稳定步长。
- **离线轨迹调参升级**：改为 80/20 分层留出验证 + 局部坐标搜索防过拟合；设置页新增「还原默认滑行参数」（保留偏移、短语与样本）；每新增 50 条轨迹在键盘收起空闲时自动后台验证调参。
- **智能联想与脏数据自动清理**：单字上文仅保留/提权 ≤ 4 字词组，并在加载时自动清理历史长句联想与编码长度错配的旧热词。

## 编辑交互增强
- **「只清空光标前的内容」空前缀回退**：开启该开关后，光标前无内容时再次触发清空会自动清空输入框剩余全部内容（依然支持撤回恢复）。
