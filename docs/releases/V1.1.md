# CJIME V1.1 更新说明

## 滑行与自学习优化
- **本地滑行与智能联想自递进校准**：持续记录个人指腹落点偏移、高频热词/整句、滑行混淆纠错（坏码 → 真码）及联想正强化/误选降权；支持一键导出/导入自学习备份（`.zip`）与脱敏轨迹日志（`.jsonl.gz`），支持离线回放调优滑行参数。
- **修复快打误触滑行符号**：提高 26 键滑行模式下快速上下拂动符号的距离门槛并收窄竖直角度，同时在双手交叠连打时豁免快速拂动，避免类似快打 `naniys` 误触输出 `>` 的情况。
- **修复自学习边界问题**：拦截半截匹配导致的编码与汉字长度错配热词；句内多步改错时不再顺带正强化尚未修改的后缀错词。
- **合并上游九键滑行与词库优化**：支持按前置组合挑选同形编码、出界拉回不作废、所有音节可滑出；同步清理词组碎片并恢复常用词排序。

## 拼音编辑与候选栏体验
- **拼音编辑条点按定位与防闪白/防位移**：
  - 点击拼音任意位置打开编辑条时，光标一步直接落到点击处，并在音节分界附近自动吸附（无展开动画，不再先闪旧光标再跳动）。
  - 悬浮预览气泡与编辑条统一复用同一悬浮窗口与模糊层，移除点击涟漪，彻底消除打开和关闭时的闪白。
  - 预览态光标改为 0 宽绘制并按实际渲染宽度决定是否插入折行零宽空格，消除打开/收起时的编码间距回缩；修复 26 键收起编辑条后光标后分词符号丢失的问题。
  - 去掉暗色模式下独立悬浮编码栏的文字阴影与托底光晕。
- **候选栏与工具栏交互精简**：
  - 去掉功能栏所有覆盖层（菜单、剪贴板、表情、编辑、方案、符号等）及候选展开页的向下展开动画，切换即刻响应。
  - 去掉候选栏剪贴板预览词条前的小图标，收紧胶囊边距。
  - 已选词铅笔编辑角标缩小并抬至候选顶边，不再遮挡文字右上角。

## 键盘布局与新功能
- **数字与符号键盘对齐优化**：
  - 调换数字键盘左下角「中文」与「!@#」符号键位置。
  - 符号键盘底栏「中文」「123」「删除」及分类标签宽与上方符号网格逐列对齐，并统一采用标准键距；数字键盘同步对齐为相同键距与两侧列宽。
- **新增实用开关与上游修复**：
  - 新增「点一下 Shift 锁定大写」开关（默认关）。
  - 新增「选完符号自动返回」开关（默认关）。
  - 实体键盘纯大写候选不画编号，翻页键按设置交标点表；同步 `librime` 引擎提速、启停方案加速、键盘收起省电、抬起震动与语音插件选择修复。
